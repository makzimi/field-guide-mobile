# README image sources

These images accompany Field Guide's public README.

- `android-list.png` and `android-detail.png`: original Android app captures used in the Field Guide introduction to *New Bottlenecks*. They show the Android design published in this repository.
- `flutter-list.png` and `flutter-detail.png`: exact copies of this repository's `samples/flutter/test/goldens/p37/list-light-1.0.png` and `detail-light-1.0.png`. These are rendered golden test baselines, not device captures.
- `testing-pyramid.png` and `checks-pyramid.png`: full reveal states exported from *New Bottlenecks: AI in Mobile Development*, revision R30-4, PDF pages 69 and 74. The testing pyramid retains its Mike Cohn attribution. The checks pyramid is the talk's teaching model. Tool names on the slides show broader options, not a list of dependencies installed in this repository.
- `signposts-and-moats.png`: original AI-generated illustration from the presentation's signposts-and-moats explanation.

The README supplies text descriptions and source links so the ideas remain accessible without the images. Only these selected visuals are included; the presentation itself is not bundled.
